Comprehensive Guide to IPv4 Subnetting & CIDR Mathematics

Published by CalcWorld Engineering Team • Aligned with IETF RFC 4632 and Cisco Networking Academy Standards

1. Introduction to IPv4 Addressing & CIDR Notation

An Internet Protocol Version 4 (IPv4) address is a 32-bit numeric identifier assigned to network interfaces connected to a computer network. To make these binary identifiers readable by network administrators, IPv4 addresses are formatted using dotted-decimal notation. Under this format, the 32 total bits are partitioned into four 8-bit groupings known as octets, separated by periods (e.g. 192.168.1.1). Because each octet comprises exactly 8 bits, its decimal value ranges from 0 (00000000 in binary) to 255 (11111111 in binary).

In early networking protocols, IP addresses were categorized into rigid architectural classes: Class A (first octet 1-126), Class B (first octet 128-191), and Class C (first octet 192-223). However, this fixed allocation strategy caused severe IP address exhaustion and inefficient route aggregation. In 1993, the Internet Engineering Task Force (IETF) formally introduced Classless Inter-Domain Routing (CIDR) under RFC 4632. CIDR replaced classful boundaries with variable-length subnet masking (VLSM), represented by prefix notation such as /24. The prefix length specifies the exact number of contiguous high-order bits dedicated to identifying the network segment.

2. Binary Mathematics of Subnetting & Bitwise AND Operations

At the hardware level, network routers do not process decimal numbers. Instead, routers perform logical bitwise operations on binary streams to determine packet routing destinations. The core operation used to identify a network boundary is the bitwise AND operation between an IP address and a subnet mask.

The truth table for a bitwise AND operation yields a value of 1 if and only if both input bits are 1. If either bit is 0, the output evaluates to 0. Consider an IP address of 192.168.1.100 paired with a subnet mask of 255.255.255.0 (/24):

IP Address: 11000000.10101000.00000001.01100100 (192.168.1.100)
Subnet Mask: 11111111.11111111.11111111.00000000 (255.255.255.0)
Bitwise AND: 11000000.10101000.00000001.00000000 (192.168.1.0)

The resulting address, 192.168.1.0, is the official Network Address. Similarly, the Broadcast Address is derived by replacing all host bits with 1s (or performing a bitwise OR between the Network Address and the Wildcard Mask). In this example, setting the final 8 host bits to 1 yields 192.168.1.255.

3. Network Bits vs. Host Bits & Capacity Formulas

Every IPv4 subnet mask divides the 32-bit address space into two distinct functional components:

  • Network Bits (N): Defined by the CIDR prefix length. These bits remain fixed for every device inside the specific subnet block.
  • Host Bits (H): The remaining bits, calculated as H = 32 - N. These bits are assigned uniquely to individual network interfaces.

The mathematical formula to determine total available IP addresses within a prefix is 2^H. However, in conventional network deployments, two specific addresses per subnet are reserved:

  1. The Network Identifier (all host bits set to 0), which identifies the network segment in routing tables.
  2. The Broadcast Identifier (all host bits set to 1), which sends packets simultaneously to every host on that subnetwork.

Therefore, the formula for total Usable Host Addresses is 2^(32 - N) - 2. For instance, a /24 prefix provides 2^8 - 2 = 254 usable host IPs. Important exceptions include point-to-point links governed by RFC 3021 (/31 prefixes, providing 2 usable addresses without traditional network/broadcast reservations) and host routes (/32 prefixes, representing a single specific IP interface).

4. RFC 1918 Private IP Spaces vs. Public Internet Addressing

To mitigate global IPv4 address exhaustion, RFC 1918 defined three designated IP address ranges reserved strictly for private local networks:

10.0.0.0 /8 Range: 10.0.0.0 — 10.255.255.255
Total IPs: 16,777,216
172.16.0.0 /12 Range: 172.16.0.0 — 172.31.255.255
Total IPs: 1,048,576
192.168.0.0 /16 Range: 192.168.0.0 — 192.168.255.255
Total IPs: 65,536

Private IP addresses are non-routable over the public internet. Organizations deploy Network Address Translation (NAT) gateways to translate internal RFC 1918 private IP addresses into a public IPv4 address when accessing external internet destinations. Other reserved ranges include Loopback addresses (127.0.0.0/8), Automatic Private IP Addressing (169.254.0.0/16), and Carrier-Grade NAT (100.64.0.0/10 per RFC 6598).

5. Worked Subnetting Scenario: Partitioning a /24 Block

Suppose a network architect receives a parent allocation of 192.168.1.0/24 and must segment it into 4 equal subnets to isolate Engineering, Human Resources, Finance, and Operations.

To create 4 equal subnets, we calculate the required additional network bits using 2^B >= 4, where B = 2 bits. Adding 2 bits to the original /24 prefix yields a new CIDR prefix length of /26 (255.255.255.192). Each /26 subnet contains 2^6 = 64 total IP addresses (62 usable).

A CIDR prefix indicates the number of 1 bits in a 32-bit binary sequence. For /24, set 24 ones followed by 8 zeros: 11111111.11111111.11111111.00000000. Converting each 8-bit octet into decimal yields 255.255.255.0.
A Subnet Mask uses 1s to represent network bits and 0s to represent host bits. A Wildcard Mask is the inverse (bitwise NOT): 0s represent network bits that must match exactly, while 1s represent host bits that can be ignored (commonly used in Cisco Access Control Lists).
